# Bluey S1 可玩游戏分析（Codex）

本文作为第一季游戏可玩性分析文档长期保留。它不是实现规格，也不是路线图唯一来源；它的职责是帮助后续从 Bluey 第一季剧情中挑选适合做成现实亲子游戏的候选，并把剧情设定转译成 App 可主持的任务卡与随机事件。

权威实现规范见 `docs/game-design-patterns.md`。产品状态和路线图见 `REQUIREMENTS.md`。

## 分析口径

一个剧集游戏适合被深度集成，需要同时满足四个条件：

1. **现实可玩**：家庭或户外常见场景能玩，不依赖复杂道具。
2. **亲子关系强**：家长有明确表演、配合、主持或被孩子指挥的空间。
3. **规则可主持**：App 能通过任务卡、随机事件、倒计时、结果判定或记录增强体验。
4. **Bluey 味道明确**：保留剧集里的家庭幽默、规则冲突、轮流、合作或情感转折。

不适合深度集成的情况：

- 剧情核心是情绪观察、生活片段或安静叙事，缺少可重复游戏规则。
- 现实动作风险较高，需要奔跑碰撞、攀爬家具或抢夺物品。
- App 很难介入，强行做只会变成屏幕小游戏。

## 通用转译模板

每个候选游戏都按同一套结构分析：

```text
剧集锚点：这一集最核心的游戏、冲突和笑点。
现实玩法：家庭实际怎么玩，需要哪些人、空间和材料。
App 角色：App 是主持器、事件牌、计时器、遥控器、裁判还是记录器。
任务阶梯：5 级任务卡，从入戏热身到高潮挑战。
随机事件：剧情事件、规则变化、亲子互动三类混合。
安全边界：需要降级或避开的动作。
优先级：高 / 中 / 低。
```

## 已深度集成游戏

### S1E1 魔法木琴

**剧集锚点**：魔法木琴可以冻住和解冻别人。核心冲突是 Bluey 不愿意轮流，Bingo 最后表达感受，姐妹合作重新掌握魔法。

**现实玩法**：用勺子、笔、玩具小棒等当“木琴锤”，孩子轮流当魔法师。被指到的人安全地冻住，其他人可以做温柔装扮或救援。

**App 角色**：虚拟 Ding 按钮、任务主持、随机魔法事件、轮流提醒。

**任务阶梯**：

1. 做个 Ding：冻住一个人，再解冻。
2. 轮流魔法师：把木琴交给别人，让每个人都有魔法。
3. 傻傻雕像：冻住后摆安全又好笑的姿势。
4. Bingo 救援：被冻住的人由另一个玩家偷偷救援。
5. 全家合作：完成一轮团队魔法，打败“抢到木琴”的家长。

**随机事件**：爸爸抢木琴、厕所休息、只能眨眼回答、花园小矮人、静音魔法、该 Bingo 了。

**安全边界**：不能乱画脸，不能推拉冻住的人，装扮只用轻软道具。

**优先级**：高，已经实现。

### S1E3 顶气球

**剧集锚点**：最后一个气球不能落地。爸爸把简单游戏加到过分热闹，气球飞出屋外，邻居参与救球。

**现实玩法**：全家在空旷区域用手、头、手臂轻轻顶气球，不让它落地。可单人挑战，也可合作接力。

**App 角色**：计时器、排行榜、任务卡、随机事件主持。

**任务阶梯**：

1. 红气球醒醒：全家轻轻顶 5 下。
2. 轻轻碰挑战：控制力度，不拍太重。
3. 客厅小旅行：把气球送到安全地点。
4. 全家接力：按顺序每个人都碰一次。
5. Wackadoo 大挑战：连续完成指定次数不落地。

**随机事件**：气球飘到安全线外、Lucky 的爸爸在看、慢动作模式、单手模式、名字接力、气球想去沙发岛。

**安全边界**：不用风扇/吹叶机，不追出安全区域，不踩沙发和家具。

**优先级**：高，已经实现。

### S1E4 爸爸机器人

**剧集锚点**：孩子不想收拾，启动 Daddy Robot 代劳；机器人误判目标并故障，最后孩子意识到应该自己收拾。

**现实玩法**：家长扮演机器人，孩子发指令。机器人会听错、卡顿、短路，需要孩子维修。

**App 角色**：指令面板、故障弹窗、修理交互、任务推进。

**任务阶梯**：

1. 热身：发几个简单指令。
2. 指挥大师：使用不同类型指令。
3. 故障维修：修复几次机器人故障。
4. 全能遥控：尝试所有指令。
5. 机器人大师：完成最终任务，让机器人休息，孩子参与收拾。

**随机事件**：短路、电量告急、病毒入侵、程序卡死、音量失控、妈妈机器人。

**安全边界**：家长动作要慢，抱起孩子、扔进“垃圾桶”等剧中动作只做口头表演或软垫安全版本。

**优先级**：高，已经实现。

### S1E5 影子陆地

**剧集锚点**：只能踩影子，阳光是鳄鱼出没的海。Coco 想走捷径，Bluey 坚持规则让游戏更好玩，最后云影救场。

**现实玩法**：户外晴天踩影子移动；室内可用手电筒和抱枕做安全岛。

**App 角色**：鳄鱼警报、任务路线主持、随机天气/云影事件。

**任务阶梯**：

1. 找影子：发现几个安全岛。
2. 规则练习：保持在影子内完成小动作。
3. 影子接力：连续移动到多个影子。
4. 穿越鳄鱼河：规划路线到终点。
5. 云影冲刺：在短暂安全窗口里全家合作到达。

**随机事件**：云遮住太阳、鳄鱼发现你、影子在移动、不能走捷径、云朵赛跑。

**安全边界**：户外要远离道路和停车区域；跳跃距离短，不要求孩子做危险大跨步。

**优先级**：高，已经实现。

### S1E19 抓娃娃机

**剧集锚点**：Bluey 和 Bingo 想赢奖品，家长在家做爪子机。Bandit 故意让胜利变难，最后爪子故障，全家用挠痒解决。

**现实玩法**：家长当爪子，小玩具当奖品。孩子做任务挣币，再用口头指令操控家长的手抓奖品。

**App 角色**：任务卡抽取、硬币记录、抓取结果判定、故障弹窗、结算。

**任务阶梯**：

1. 挣第一枚币：完成简单家务或互动。
2. 投币抓取：学会口头指挥爪子。
3. 奖品选择：选择想要抓的玩具。
4. 特殊奖品诱惑：加入取舍和轮流。
5. 爪子故障：挠痒修复并完成最后庆祝。

**随机事件**：抓住、滑掉、爪子故障、机器太难、补偿硬币。

**安全边界**：挠痒必须温柔可停止；奖品用软玩具；不鼓励抢夺他人心爱物品。

**优先级**：高，已经实现。

## 高优先级候选

### S1E2 医院

**剧集锚点**：医生、护士、病人角色扮演，病情可以非常荒诞，检查和治疗都靠想象力。

**现实玩法**：孩子当医生或护士，家长/玩具当病人。纸卷当听诊器，白纸当 X 光片，贴纸当药。

**App 角色**：病情生成器、检查流程卡、治疗任务、出院庆祝。

**任务阶梯**：

1. 挂号：给病人起名字，问哪里不舒服。
2. 检查：听心跳、量体温、看 X 光。
3. 诊断：抽一张荒诞病情卡。
4. 治疗：开药、包扎、做温柔手术。
5. 出院：病人表演恢复健康，全家鼓掌。

**随机事件**：急诊来了、X 光里有奇怪东西、药房缺货、玩具病人插队、医生也打喷嚏。

**安全边界**：不使用尖锐物品，不模拟真实打针疼痛，不把医疗恐惧做成惩罚。

**优先级**：高。它材料少、低体力、角色清晰，很适合做下一款安静型可玩游戏。

### S1E6 魔法雕像商店

**剧集锚点**：雕像保持不动，店主和顾客互动，孩子通过“偷偷动一下”制造笑点。

**现实玩法**：一人当店主，一人当顾客，一人当雕像。顾客转身时雕像不能动，背过去时雕像可以轻轻换姿势。

**App 角色**：顾客回头倒计时、姿势任务卡、随机促销事件、抓包判定。

**任务阶梯**：

1. 入店：雕像摆第一个安全姿势。
2. 转身：顾客背过去，雕像偷偷换一次姿势。
3. 验货：顾客检查雕像有没有动。
4. 退款危机：雕像差点被发现，店主想办法解释。
5. 雕像展：全家一起完成一组雕像作品。

**随机事件**：顾客突然回头、雕像打喷嚏、店主促销、魔法姿势升级、退款警报。

**安全边界**：姿势不要求单脚太久，不让孩子在高处站立，不追跑抓人。

**优先级**：高。规则简单，笑点强，很适合任务卡和倒计时。

### S1E7 假装烧烤

**剧集锚点**：孩子用自然材料和玩具模拟烧烤、点单、上菜，生活技能和角色扮演结合。

**现实玩法**：收集树叶、花瓣、积木、玩具食物当食材。孩子当烧烤师、顾客、服务员。

**App 角色**：订单队列、食材任务、突发状况、顾客评分。

**任务阶梯**：

1. 备料：找到几种颜色的安全食材。
2. 点单：顾客说出想吃的组合。
3. 烹饪：烧烤师按顺序制作。
4. 突发状况：缺盐、烤焦或下雨搬家。
5. 上菜评分：顾客给出温柔评价。

**随机事件**：客人加单、烤焦了、缺盐了、下雨了、Bingo 要沙拉。

**安全边界**：不接触真实火和热锅；户外采集只用安全可碰的自然物，不入口。

**优先级**：高。生活感强，适合家庭和户外，教育价值自然。

### S1E10 酒店

**剧集锚点**：酒店经营、客人入住、服务和投诉，角色分工清晰。

**现实玩法**：孩子经营家庭酒店。纸片当房卡，小本子登记，抱枕当床。

**App 角色**：特殊客人卡、房间任务、服务事件、离店评分。

**任务阶梯**：

1. 开门营业：准备房卡和房间。
2. 办理入住：登记客人名字和需求。
3. 客房服务：铺床、送早餐、打扫。
4. 特殊客人：处理投诉或迷路。
5. 离店评分：客人评价服务，全家庆祝。

**随机事件**：房卡丢了、客人要早餐、房间太吵、停电、五星好评。

**安全边界**：服务任务只用轻软道具；不要求搬重物。

**优先级**：中高。它非常适合低体力室内角色扮演，但 UI/任务需要更多角色管理。

## 中优先级候选

### S1E9 骑马游戏

**剧集锚点**：家长当马，孩子骑马和举办马儿婚礼，亲子身体互动很强。

**现实玩法**：家长四肢着地或坐姿当马，孩子轻坐或扶背指挥。也可以改成“抱枕马”“椅子马”降低体力要求。

**App 角色**：安全赛道主持、障碍卡、婚礼仪式卡、休息提醒。

**任务阶梯**：

1. 慢慢走：马儿热身。
2. 转弯：孩子发方向指令。
3. 障碍：绕过抱枕或椅子。
4. 婚礼/救援：加入剧情仪式。
5. 安全终点：马儿休息，孩子照顾马。

**随机事件**：马儿饿了、马儿要休息、婚礼开始、障碍出现、观众鼓掌。

**安全边界**：体力和腰背风险高，必须给家长退出和替代玩法。

**优先级**：中。亲子感强，但安全和家长体力约束更高。

### S1E13 Spy Game

**剧集锚点**：孩子组成队伍执行间谍任务，涉及角色分工、秘密通信和团队合作。

**现实玩法**：室内寻物、传递暗号、避开“激光线”（毛线或想象线）。

**App 角色**：任务简报、暗号生成器、警报事件、团队进度。

**任务阶梯**：

1. 领取代号：每个人选间谍名。
2. 找线索：找到一个安全物品。
3. 传暗号：用动作或声音传递信息。
4. 警报响起：全员冻结或躲到安全点。
5. 完成任务：把线索送回基地。

**随机事件**：警报、暗号变更、线索转移、基地需要帮助。

**安全边界**：不要求奔跑追逐，不用真绳子绊脚。

**优先级**：中。很好玩，但需要新增游戏数据和更丰富任务池。

### S1E23 Shops

**剧集锚点**：孩子开商店，角色不断变化，社交协商是核心。

**现实玩法**：玩具当商品，孩子轮流当店主和顾客。

**App 角色**：商品卡、顾客需求、价格/付款提示、店铺事件。

**任务阶梯**：

1. 摆货：准备三样商品。
2. 开张：顾客提出需求。
3. 推荐：店主介绍商品。
4. 突发：商品缺货或顾客改变主意。
5. 打烊：整理商店并发感谢卡。

**随机事件**：大减价、顾客排队、商品掉了、需要包装。

**安全边界**：小物件不入口，收拾环节要轻松。

**优先级**：中。与酒店、烧烤有重叠，可后置。

### S1E27 Pirates

**剧集锚点**：冒险、想象、船和海盗情境，适合客厅变成大海。

**现实玩法**：毯子当船，抱枕当岛，地图或纸片当宝藏。

**App 角色**：藏宝图、海浪事件、船员任务、宝藏结算。

**任务阶梯**：

1. 上船：选船员角色。
2. 找岛：移动到安全岛。
3. 避浪：全员保持平衡。
4. 海盗事件：修船或找宝藏。
5. 开宝箱：分享奖励。

**随机事件**：大浪、风变向、宝箱线索、船需要修理。

**安全边界**：不跳家具，不蒙眼奔跑。

**优先级**：中。视觉和想象空间大，但要小心安全。

## 低优先级或工具型候选

### S1E11 Bike

适合做“鼓励练习/坚持挑战”的剧情灵感，但现实中骑车安全变量太多。更适合作为户外活动建议或成长主题卡，不建议短期深度集成。

### S1E14 Takeaway

生活混乱感强，但玩法不如烧烤、酒店清晰。可以抽取成“等待时间小游戏”或随机事件素材。

### S1E28 Grannies

角色扮演好笑，但动作核心较散。适合做姿势/声音任务包，不急着单独成深度游戏。

### S1E33 Trampoline

现实玩法有明确设备依赖和安全风险。不建议作为通用可玩游戏，只可作为有条件家庭的活动建议。

### S1E42 Hide and Seek

现实可玩，但 App 介入价值有限。可以做倒计时/找人提示工具，不必深度集成。

## 下一批推荐顺序

1. **医院**：低体力、材料少、亲子角色清晰，适合补一个安静型深度游戏。
2. **魔法雕像商店**：规则简单，笑点直接，倒计时和随机事件都很自然。
3. **假装烧烤**：生活技能和户外/室内材料收集结合，教育价值高。
4. **酒店**：角色扮演完整，但需要更多角色和服务流程设计。
5. **Spy Game**：很有潜力，但任务池和安全设计要更细。

短期建议先做前三个。它们能覆盖安静照顾、身体控制、生活扮演三种不同气质，和已实现的五款游戏互补。

## 设计检查问题

后续分析新剧集时，用这几个问题快速判断是否值得深度集成：

- 孩子听完一句话能马上开始玩吗？
- 家长有没有好玩的表演位置？
- App 的随机事件会让现实游戏更好玩，还是只是在打断？
- 任务卡能不能自然排成 5 级阶梯？
- 这个玩法是否能在小客厅、普通家庭和 10 分钟内成立？
- 剧集里的情感核心是否被保留下来？
