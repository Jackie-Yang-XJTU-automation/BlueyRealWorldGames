# 可玩游戏设计模式

本文是 BlueyRealWorldGames 所有深度可玩游戏的唯一设计规范。可玩游戏的目标不是把孩子留在屏幕上，而是让 App 成为现实亲子游戏的主持器：发任务、制造意外、记录节奏，真正的游戏发生在客厅、院子、公园和家人之间。

## 设计原则

- **剧情有根**：每个游戏必须先参考对应剧集资料，优先阅读 `docs/superpowers/data/SxEy-*.md`，必要时再查 `docs/superpowers/scripts/SxEy-*.md`。
- **现实可玩**：任务必须能在真实家庭场景中完成，材料常见、动作安全、家长能理解并参与。
- **Bluey 味道**：保留剧集里的冲突、笑点和情感核心，例如轮流、守规则、合作、家长夸张表演、孩子主导想象。
- **屏幕退后**：App 只做主持和节奏控制，孩子不需要长时间盯着屏幕操作。
- **阶梯推进**：任务卡必须有难度和剧情递进，不允许只是随机动作列表。

## 通用玩法骨架

每个深度可玩游戏都由两种核心内容驱动：

1. **任务卡片**：主线玩法。它告诉玩家现在要在现实中完成什么动作、协作或角色扮演。
2. **随机事件**：剧情扰动。它让游戏像 Bluey 剧集一样出现意外、笑点和临时规则变化。

运行流程统一为：

```text
准备说明 → 开始倒计时 → 任务卡推进
                 ↓
          随机事件穿插
                 ↓
暂停/继续/结束确认 → 结算或庆祝
```

技术实现仍遵守现有架构：

- 数据层：`src/data/*Tasks.ts` 和 `src/data/*Events.ts`
- 逻辑层：`src/hooks/use*Game.ts`
- 页面层：`src/pages/*Page.tsx`
- 共用组件：`CountdownOverlay`、`CommandPanel`、`RandomEventPopup`、`GameTimer`、`Leaderboard`

## 阶梯任务卡

每个游戏默认使用 5 级任务阶梯。名称可以贴合具体游戏改写，但职责不能变。

| 级别 | 目的 | 设计方式 |
|------|------|----------|
| 第1关：入戏热身 | 让孩子理解核心规则 | 动作简单、时长短、成功率高 |
| 第2关：掌握规则 | 强化本游戏最重要的约束 | 加入轮流、轻重、边界、角色职责 |
| 第3关：协作升级 | 从单人动作变成亲子配合 | 接力、救援、喊名字、家长参与 |
| 第4关：剧情冲突 | 引入剧集里的麻烦 | 爸爸捣乱、机器故障、规则变难、奖品诱惑 |
| 第5关：高潮挑战 | 形成一轮完整 finale | 全家合作完成明确目标，然后庆祝或结算 |

任务卡文案要求：

- 句子短，孩子能听懂，家长能立刻执行。
- 每张卡只传达一件事。
- 明确现实动作、次数、时间或完成条件。
- 不设计危险动作，不鼓励奔跑碰撞、攀爬家具、抢夺物品或羞辱玩家。
- 不直接复述剧情台词，改成适合家庭现实游戏的提示。

## 随机事件

随机事件必须服务于剧情和现实互动，分三类混合使用：

- **剧情事件**：来自对应剧集的冲突或笑点，例如爸爸抢木琴、气球飘走、机器人短路、云影来了、爪子故障。
- **规则变化**：临时改变玩法方式，例如慢动作、单手、只能轻轻碰、静音、换角色、救援。
- **亲子互动**：鼓励家人连接，例如击掌、拥抱、轮流、家长夸张表演、孩子指挥、全家欢呼。

随机事件文案要求：

- 事件持续时间短，通常 6-15 秒。
- 不打断核心玩法太久。
- 失败也要好笑，不惩罚孩子。
- 户外游戏要考虑天气、空间和视线；室内游戏要提醒慢走、轻碰、避开家具。

## 剧情适配标准

设计每个新游戏前，先写清四件事：

1. **剧集锚点**：这集最核心的游戏规则、冲突和情感是什么。
2. **现实玩法**：家庭实际需要哪些人、空间和材料。
3. **App 角色**：App 是裁判、主持、计时器、事件牌、遥控器还是结果判定器。
4. **安全边界**：哪些动作必须降级、替换或明确提醒。

允许做现实化改编。比如剧中爸爸用风扇和吹叶机把气球难度拉满，App 里可以改成“气球飘到安全线外，大家慢慢回到空旷区域”，保留笑点但移除风险。

## 实现检查清单

新增或重做可玩游戏时，必须满足：

- 已阅读对应 `docs/superpowers/data/` 剧情摘要。
- `src/data/*Tasks.ts` 中任务卡是 5 级阶梯设计。
- `src/data/*Events.ts` 中随机事件至少覆盖剧情事件、规则变化、亲子互动。
- 页面使用开始倒计时、暂停/继续、结束确认。
- 主线任务通过 `CommandPanel` 或等价任务卡组件展示。
- 随机事件通过 `useRandomEvent` 或同等 hook 调度。
- 游戏结束条件、胜利条件或庆祝条件清晰。
- 所有动作符合 3-8 岁儿童现实亲子游戏安全性。
- App 不要求长时间盯屏，不依赖网络，不收集个人信息。
